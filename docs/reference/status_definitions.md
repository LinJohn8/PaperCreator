# 状态定义

> 最后检查：2026-07-27。Wiki 只使用以下词。

| 状态 | 定义 |
|---|---|
| 稳定 | 有持续真实使用和回归证据；当前尚少使用 |
| 可用 | 代码接通且有相称自动验证 |
| 部分可用 | 主体工作，仍有明确链路/环境缺口 |
| 实验性 | 可运行但真实质量/协议/边界未充分验收 |
| 开发中 | 正在补齐，不能对外承诺 |
| 尚未接入 | 依赖/配置/代码存在但主链未连接 |
| 尚未实现 | 无实现代码 |
| 存在代码但未调用 | 可定位实现但没有运行入口 |
| 存在前端但缺少后端 | UI 占位，API 缺失 |
| 存在后端但缺少前端 | API 可用，UI 无入口 |
| 仅有测试数据 | 只在 fixture/smoke 中存在 |
| 已弃用 | 不推荐且计划移除 |
| 待确认 | 代码/Git/运行证据不足 |
