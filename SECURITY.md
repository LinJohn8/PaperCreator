# Security Policy

PaperCreator is an experimental local application, not a hardened production service. It should bind only to loopback interfaces unless the deployment has been independently secured.

## Reporting

For a suspected vulnerability, use GitHub's private security advisory feature for this repository when available. Do not open a public issue containing API keys, tokens, unpublished manuscripts, personal data, database files, logs with sensitive content, or a complete workbench archive.

There is no guaranteed response or patch timeline. If private reporting is unavailable, publish only a minimal, redacted description and wait for a maintainer-approved private channel before sharing reproduction data.

## Supported versions

There is currently no supported stable release. Only the latest `main` branch may receive fixes, on a best-effort basis.
